# mos_雨滴 — EffectCraft 真实雨窗效果

从零重写的雨天玻璃窗效果（v4.0.0）：水滴不再是均质球面，而是带有重力下垂梨形与不规则表面张力微扰的有机水珠；每颗水滴像一颗微型凸透镜，能清晰倒映并弯曲折射背后的窗景与光线，搭配纤细的弯月面暗接触线、底部聚光亮弧、锐利高光与三通道色散。大雨滴、小雨滴与长条雨滴三层各自独立控制密度、大小、相位与置换强度，持续往下流淌并擦净沿途雾气、融并小水珠。

像素级效果，直接改写图层画面，不写图层的变换属性。

## 安装

插件包 = `mos_rain.wasm`（单文件，无依赖）。

1. **安装（推荐）**：Effect ▸ Install Effect Plug-in… 选 `dist\zh-zh\mos_rain.wasm`（或 `dist\en-en\mos_rain.wasm`），文件会被复制进 `%APPDATA%\EffectCraft\Plug-ins`。
2. **临时加载**：Effect ▸ Load Effect Plug-in… 选 `.wasm`，只对当前会话有效。

`dist` 下有四份语言包：

```
dist/zh-zh/mos_rain.wasm   中文名称 + 中文参数（默认）
dist/zh-en/mos_rain.wasm   中文名称 + 英文参数
dist/en-zh/mos_rain.wasm   英文名称 + 中文参数
dist/en-en/mos_rain.wasm   英文名称 + 英文参数
dist/mos_rain/             兼容别名（= zh-zh）
```

## 算法亮点

1. **全分辨率解析元球场与精确梯度**：抛弃半分辨率与离散有限差分，每个雨滴直接向全分辨率缓冲累加势场 `F`、精确解析梯度 `∇F` 与势场加权折射位移。相邻水滴在接触阈值 `F = 0.30` 处自然融合出光滑液桥，并由精确像素距离 `(F - 0.30) / |∇F|` 做子像素抗锯齿，无锯齿、无虚线边。
2. **有机重力形态与真实凸透镜倒像折射**：每颗水滴带有重力下垂梨形（上尖下坠）与代数 2/3 次角谐波微扰；内部折射采用强弯曲凸透镜映射（倍率 `> 1`），上下倒映背后窗景与高光，配合 `dispersion >= 19%` 时的真三通道 R / G / B 采样，边缘呈现细腻彩虹色散。
3. **固定玻璃微痕与粘滑重力下落**：长条水痕沿固定在玻璃坐标 `y` 上的 3 频非公度蜿蜒路径铺设，领头水滴做严格单调的粘滑重力运动持续下流，沿玻璃留下渐隐残珠与擦除通道 `wbuf`，擦净玻璃雾气并带走沿途小水珠。
