# mos_雨滴 — EffectCraft 雨天玻璃

真实的雨天玻璃窗：细密水雾铺底，大小不一的圆水珠压在玻璃上，少数雨滴被拉长、
拖出逐渐变细的水痕，并沿重力方向缓慢下滑。所有雨滴都是全分辨率高度场上的
穹顶，用屏幕叠加融在一起；边缘斜率归零，不会把背景撕出硬缝。

像素级效果，直接改写图层画面，不写图层的变换属性。

| 项目 | 值 |
| --- | --- |
| 效果 ID | `mos.rain` |
| 显示名 | mos_雨滴 |
| 分类 | MOS 形变 |
| 版本 | 1.0.0 |
| 作者 | MOSSLS |

## 安装

插件包 = `mos_rain.wasm`（单文件，无依赖）。

1. **安装（推荐）**：Effect ▸ Install Effect Plug-in… 选
   `dist\zh-zh\mos_rain.wasm`（或 `dist\mos_rain\mos_rain.wasm`），
   文件会被复制进 `%APPDATA%\EffectCraft\Plug-ins`，之后每次启动自动加载。
2. **临时加载**：Effect ▸ Load Effect Plug-in… 选 `.wasm`，只对当前会话有效。
3. **命令行**：
   `effectcraft-cli script --eval "app.run('effect.plugins.load', {path: '…\\mos_rain.wasm'})"`

卸载 = 删掉 `Plug-ins\mos_rain.wasm`。同名插件不会覆盖，换版本前先删旧文件。

`dist` 下有四份语言包，按界面语言选一份即可：

```
dist/zh-zh/mos_rain.wasm   中文名称 + 中文参数（默认）
dist/zh-en/mos_rain.wasm   中文名称 + 英文参数
dist/en-zh/mos_rain.wasm   英文名称 + 中文参数
dist/en-en/mos_rain.wasm   英文名称 + 英文参数
dist/mos_rain/             兼容别名（= zh-zh）
```

四份产物体积约 24.9 KB，manifest 内嵌在 wasm 的 data 段里。

## 参数

共 17 个界面参数，分三组。`tint` 展开成 r / g / b / a，所以 `ec_render` 收到
20 个 f64，下标 0–19 与下表顺序一致。

### 雨滴

| # | 参数 | id | 类型 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 折射强度 % | `amount` | slider | 120 | 0 – 300 | 雨滴的位移总量。100 % 是标准水量 |
| 2 | 雨滴大小 % | `size` | slider | 50 | 0 – 100 | 主雨滴半径占网格的比例 |
| 3 | 分布密度 % | `density` | slider | 48 | 0 – 100 | 主雨滴的数量；越高越容易叠成水洼 |
| 4 | 长条雨滴 % | `streak` | slider | 35 | 0 – 100 | 被重力拉长、带拖尾的雨滴比例 |
| 5 | 拖尾长度 % | `trail` | slider | 40 | 0 – 100 | 拖尾相对雨滴半径的长度，0 时只剩短尾 |
| 6 | 细小雨滴 % | `mist` | slider | 50 | 0 – 100 | 2–4px 雾滴的密度，铺满玻璃的细水雾 |
| 7 | 流速 % | `speed` | slider | 25 | 0 – 200 | 长条雨滴下滑速度；0 = 静止 |

### 质感

| # | 参数 | id | 类型 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| 8 | 色散 % | `dispersion` | slider | 12 | 0 – 100 | R / B 通道的折射差，边缘彩虹 |
| 9 | 高光 % | `highlight` | slider | 110 | 0 – 300 | 湿润镜面反光 + 锐利亮点 |
| 10 | 边缘光 % | `rim` | slider | 50 | 0 – 300 | 雨滴边缘的菲涅耳亮环，只亮迎光侧 |
| 11 | 光照角度 | `light_angle` | angle | 135 | 0 – 360 | 0° = 右，90° = 上（屏幕坐标） |
| 12 | 磨砂 % | `frost` | slider | 0 | 0 – 100 | 只糊雨滴本身，背景保持清晰 |
| 13 | 色调 | `tint` | color | 淡蓝 [0.72, 0.88, 1.0, 1.0] | — | 只染雨滴的透射光 |
| 14 | 染色 % | `tint_amount` | slider | 0 | 0 – 100 | 色调的混合量 |

### 输出

| # | 参数 | id | 类型 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 15 | 采样 | `sampling` | popup | 0 = 双线性 | 双线性 / 双三次 / 最近邻；双三次只用于主采样 |
| 16 | 边缘 | `edge_mode` | popup | 0 = 拉伸边缘 | 拉伸 / 重复 / 镜像 / 透明 |
| 17 | 混合 % | `mix` | slider | 100（0 – 100） | 和原图的混合比例 |

参数只作用于雨滴：高光、磨砂、染色、色散都在雨滴的局部尺度内生效，平坦的
玻璃不会被整体提亮或糊掉。`折射强度`、`磨砂`、`染色` 都为 0，且高光 / 边缘光
也关掉时，效果直接跳过（返回原图）。

## 用法建议

- **整段画面一起淋雨**：把效果加到**调整层**（Layer ▸ New ▸ Adjustment Layer）
  或预合成层上，让它一次折射整个合成；加在单个图层上时只能搬动该层自己的
  像素，密度大时图层包围盒边缘会缺少雨滴。
- **小雨 / 毛毛雨**：`大小` 35–45，`密度` 25–40，`长条` 15–25，
  `拖尾` 25–35，`细雨` 70–90，`流速` 10–20，`折射` 90–110。
- **中雨（默认）**：120 / 50 / 48 / 35 / 40 / 50 / 25，适合大多数镜头。
- **暴雨**：`折射` 150–190，`大小` 65–80，`密度` 80–95，`长条` 55–70，
  `拖尾` 55–70，`细雨` 80–100，`流速` 60–90。画面会被水珠盖住大半，
  适合做“隔着雨窗看人”的主观镜头。
- **只有水雾**：`大小` 5–12，`密度` 0，`长条` 0，`细雨` 100，`折射` 80–110，
  `高光` 120–160。像刚起雾的冷玻璃。
- **长水痕**：`长条` 70–100，`拖尾` 80–100，`流速` 40–70。雨滴会拉出很长的
  下滑轨迹，适合做时间流逝。
- **磨砂玻璃**：`磨砂` 30–70，同时把 `高光` / `边缘光` 降到 40–70，避免模糊的
  水滴上还留一圈锐利亮边。
- **冷色玻璃**：`色调` 取淡蓝 / 淡青，`染色` 10–25；只染雨滴，背景不变色。
- **色散** 8–25 % 最自然；超过 45 % 是风格化的棱镜效果。
- `边缘 = 透明` 适合把雨滴放在透明图层上；折射很大时雨滴边缘会取到画面外的
  透明像素，出现一圈缺口，把 `折射强度` 降到 150 以下通常就干净了。

## 算法

**1. 全分辨率高度场。** 雨滴只有几个像素宽，半分辨率会把珠子边缘糊掉，所以
高度场和画面同尺寸。主雨滴画在抖动网格上：`cell = max(8, min(w,h) × 0.065)`，
每个格子用哈希决定是否保留（阈值 `0.15 + 0.85 × density`），所以 `密度` 管
数量、`大小` 管半径。半径 `r = cell × (0.18 + 0.50 × size) × (0.42 + 1.05 × hash) × (0.75 + 0.55 × 区块系数)`，
再乘一个 0.82 的收紧系数，让默认落在“中雨”的尺度上，而不是铺成一整面
气泡膜。

**2. 穹顶。** 每颗雨滴是轴对齐椭圆，归一化半径 `q`，高度
`v = (1 − q²)(1 − q⁸) × vh`。中心保留斜率（放大背景），边缘斜率收到 0，珠子
边界不会把背景撕出一条缝。所有雨滴用屏幕叠加 `old + v − old·v` 写进高度场：
两颗珠子叠在一起时会融成一个更鼓的水洼，而不是留下硬缝。

**3. 细雨层。** 更密的抖动网格（约主网格的 0.22 倍间距），半径 1–3px，高度
0.35–0.7，用 `mist` 控制保留比例。小水珠曲率大、位移被局部尺度限制在自身附近，
所以是“细密水雾”，不会在背景上搅出一圈大涟漪。

**4. 长条雨滴。** `hash < streak` 的雨滴被拉长：头部椭圆竖直半径乘 1.15–1.4，
上方拖一条解析水痕。拖尾不是叠加一串椭球，而是逐行取中心线和半宽，横截面用
同一个穹顶，宽度和高度按 `sqrt(1 − t)` 逐渐收敛到 0，横向叠一点 `sin` 摆动。
这样梯度是一条连续的水膜，而不是一圈圈珠子边。头部最后画，压住拖尾根部。

**5. 下滑。** `slide = time × speed × 0.5 × (0.5 + hash)` 像素，头部和拖尾一起
下移；超过 `h + 12r` 后从画面上方 6r 处循环回来。非长条雨滴只做 0.6px 以内的
轻微漂移。

**6. 梯度与局部尺度。** 高度场原地换成 `∂h/∂x` / `∂h/∂y`。每颗雨滴在 splat
时把自身半径写进第二张 `strength` 场（取最大值），渲染时：

- 位移 `d = 0.30 · s² · (amount/100) · ∇h`，`s` 是局部雨滴半径；
- 法线 `n = normalize(−∇h · 0.6s, 1)`；
- 位移上限 `dmax = 2.2s`。

这样 2px 的雾滴只搅动自己附近，15px 的大水珠才有厚透镜的位移量；如果用一个
全局尺度，小雾滴会把背景拧出一圈十几像素的光晕，整张图像气泡膜。

**7. 采样与色散。** 位移后按 `采样` 选项取原图；色散开启时 R 用 `1 − ca` 倍
位移、B 用 `1 + ca` 倍位移，G 取两次采样的中点。色散两路只差几个像素，固定用
双线性，双三次留给主采样。

**8. 磨砂。** 原图降到一半，做四趟盒式模糊（累积和 + 小数边界插值），再按
折射后的坐标采样、和清晰结果混合。混合量乘雨滴的局部 gate，所以只有水滴变糊，
背景保持清晰。磨砂同时压低高光 / 边缘光、压平起伏。

**9. 光照。**

- 锐利反光：在坡度空间里算法线到理想反射方向的距离，`smoothstep` 出一块
  只有几个像素宽的湿亮高光；
- 菲涅耳：Schlick 五次项，亮边只出现在迎光侧；
- 边缘环：法线平方 `n² > 0.85` 的一圈亮边，由 `rim` 单独控制；
- 背光侧边缘压暗一点，亮背景上的水滴靠这条暗轮廓才有体积；
- 很小的雾滴额外加一点散射底光，暗背景上不会消失；
- 叠加光按背景亮度衰减（`1 − 0.68·luma`），亮背景不会整颗烧成纯白。

**10. 输出。** 染色只作用于雨滴；预乘 alpha 下把 RGB 夹到 `[0, a]`，最后按
`mix` 和原图混合。

## 性能

宿主用 **wasmi 解释器**执行插件，同一份内核在 Node/V8 里快一个数量级。
下表是本机 V8（Node 22.22.2，Windows 11，单帧 `ec_render`，5 次中位数，
960×540 / 1920×1080 真实照片素材，不含合成与 PNG 编码）：

| 分辨率 | 默认 | 密雨 | 全条雨滴 | 只有细雨 | 磨砂 65% | 双三次 | 无光照 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 960×540 | 87 ms | 95 ms | 77 ms | 63 ms | 89 ms | 58 ms | 30 ms |
| 1920×1080 | 272 ms | 268 ms | 244 ms | 218 ms | 321 ms | 246 ms | 128 ms |

（“全条雨滴”= `streak 100 / trail 55`；“只有细雨”= `size 8 / density 0 /
mist 100`；无光照 = `highlight 0 / rim 0 / dispersion 0`。）

磨砂是最贵的一项（半分辨率四趟模糊 + 一次额外采样）；色散为 0 时省一次采样；
高光 / 边缘光全为 0 时省掉整段光照，约快 3 倍。全分辨率高度场是主要成本，
但它只做 splat，不做逐像素三角函数。

**预览建议。** 1080p 全分辨率每帧要过一遍解释器，实时预览不现实。把播放分辨率
降到 **50 %**（像素数 1/4）是最有效的办法；其次是关掉磨砂、把色散降到 0，
或把采样从双三次换回双线性。

## 已知限制

- 折射是 2D 高度场的梯度近似，没有真正的光线追踪、全反射或环境反射；
  水滴的“厚度感”靠穹顶、边缘环、高光和色散装出来。
- 雨滴的尺寸是风格化的。默认 50 % 在 960×540 上已经接近微距；想要真实窗玻璃
  的尺度可以把 `大小` 降到 30–40。
- 高密度时屏幕叠加会让重叠区饱和成一块平台，视觉上就是水洼；这是有意为之，
  但极端参数（`density 100` + `size 100`）会糊成一大片。
- 长条雨滴的拖尾是解析高度脊，不是流体模拟；很长（`trail 100`）时会有轻微的
  规则感，横向摆动是单频 sin。
- 细雨在 960×540 上只有 1–3px，低分辨率或强压缩后可能变成噪点；提高播放分辨率
  或降低 `细雨` 可以缓解。
- 磨砂是半分辨率模糊混合，不是 BRDF；`frost` 很高时雨滴细节会被抹平。
- `边缘 = 透明` 且折射位移很大时，会从画面外取到透明像素，边缘出现透明缺口。
- 逐像素成本高；1080p 实时预览不现实，见上面的预览建议。
- 光照是叠加式的，背景本身就接近纯白时边缘仍会贴近 1.0，只是不会整圈过曝。
