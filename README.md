# mos_雨滴 — EffectCraft 真实雨窗与自定义贴图液态折射效果

v5.0.0 升级为 **External Effect Helper（外部效果辅助程序）**：保留全部程序化雨滴模拟的同时，新增**「自定义图层」**控件，支持按**亮度**或 **Alpha** 提取任意图层的边缘与明暗光照轮廓，套用相同的液态曲率、凸透镜折射位移、三通道色散、弯月面暗接触线与方向高光。

像素级效果，直接改写图层画面，不写图层的变换属性。

## 安装与自动加载

由于 EffectCraft 只有外部效果辅助程序支持 `type: "layer"`（跨图层选择器），`mos_雨滴` 从 v5.0.0 起由独立进程 `effectcraft-helper-mos-rain.exe` 提供。运行一键构建安装脚本：

```powershell
.\build.ps1
```

脚本会自动完成：
1. 编译 `helper/` 发布版至 `dist\effectcraft-helper-mos-rain.exe`；
2. 复制到 `%APPDATA%\EffectCraft\helpers\effectcraft-helper-mos-rain.exe`；
3. 若 `%APPDATA%\EffectCraft\Plug-ins\mos_rain.wasm` 仍存在，自动将其移至 `%APPDATA%\EffectCraft\Plug-ins-disabled\mos_rain.wasm`，避免与旧版 ID 冲突；
4. 安装开机自加载脚本到 `%APPDATA%\EffectCraft\Scripts\Startup\mos-load-helpers.jsx`（依赖 **设置 ▸ 脚本与表达式 ▸ 允许脚本写入文件和访问网络** 开启）。

- **重启 EffectCraft**：效果列表「MOS 形变」下会自动出现 **mos_雨滴**。
- **已经开着的窗口**：无需重启，直接在菜单点击 **效果 ▸ 扫描效果辅助程序...** 即可立即生效。

## 自定义图层使用说明

1. **提取机制**：
   - `亮度`模式在预乘 RGB 上计算 Rec.709 亮度，透明像素自动为 0；超过`边缘阈值 %`后，内部明暗差异同样会转化为高低起伏的折射坡度，适合用黑白噪声、光斑、3D 渲染球或渐变来雕刻自定义光照液滴。
   - `Alpha`模式直接提取图层透明通道，配合子像素级各向同性高斯平滑边界，适合用于文字、Logo、遮罩图形边缘的液态玻璃凸起。
   - 被选中的自定义图层记得在时间线上关掉自身小眼睛（避免遮挡底图），`mos_雨滴`仍可通过 `layer_input` 正常读取其像素。
2. **已知限制（参考图层变换）**：
   - 与 `mos_灯光混合` 一样，EffectCraft 的外部辅助程序 `layer_input` 回调只返回目标图层自身应用完自身遮罩与上方效果后的画面，**不包含该图层在合成里的位置 / 缩放 / 旋转变换**；宿主会按尺寸对齐重采样进本层网格。
   - 若要让自定义贴图随**位置 / 缩放 / 旋转**动画移动，请把该贴图先放入**与主合成等大的预合成**中做动画，再在「自定义图层」选择该预合成。

## 自测命令

```powershell
# 1. 构建并安装
.\build.ps1

# 2. 协议、缓存/超时健壮性、数值回归与样张测试（输出到 tests/out/）
python tools/test_helper.py

# 3. EffectCraft 真引擎 CLI 渲染验证（先扫描 helpers 再跑 script.run）
$code = Get-Content tools\engine_check.jsx -Raw
@'
{"command":"effect.helpers.scan","params":{}}
'@ + "`n" + (@{command="script.run"; params=@{code=$code; name="engine_check.jsx"}} | ConvertTo-Json -Compress) |
  & "C:\Program Files\EffectCraft\effectcraft-cli.exe" run --commands -
```
